# C - Structures, typedef

This project is part of the Software Engineering curriculum at Holberton School, focusing on structures and the `typedef` keyword in the C programming language.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Compiled on Ubuntu 20.04 LTS using `gcc`, using the options `-Wall -Werror -Wextra -pedantic -std=gnu89`
- All files should end with a new line
- A `README.md` file at the root of the project folder is mandatory
- Code must follow the Betty style (`betty-style.pl` and `betty-doc.pl`)
- No global variables allowed
- All header files must be include guarded

## Tasks
* **0. Poppy**: Define a new type `struct dog` with elements `name`, `age`, and `owner`.
