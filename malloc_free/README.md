# 0x0a. C - malloc, free

This project is part of the low-level programming curriculum at Holberton School. It focuses on learning how to use dynamic memory allocation in C using `malloc` and `free`.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Compilation on Ubuntu 20.04 LTS using `gcc` with options: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- All files must end with a new line.
- Code must follow the **Betty** style guidelines.

## Tasks & Files

| File | Description |
| ---- | ----------- |
| `0-create_array.c` | A function that creates an array of chars, and initializes it with a specific char. |
