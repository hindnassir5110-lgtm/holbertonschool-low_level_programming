# C - More malloc, free

This project is part of the Software Engineering curriculum at Holberton School. It covers advanced concepts of dynamic memory allocation in C using `malloc`, `free`, and standard functions like `exit`, `calloc`, and `realloc`.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Compiled on Ubuntu 20.04 LTS using `gcc` with options `-Wall -Werror -Wextra -pedantic -std=gnu89`
- All files should end with a new line
- Code must follow the Betty style

## Tasks & Files
* **0-malloc_checked.c**: A function that allocates memory using `malloc`.
* **main.h**: Header file containing the prototypes of all functions created in this project.
